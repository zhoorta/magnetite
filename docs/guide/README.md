# Documentation

Magnetite is a self-hosted music player for the browser, with loudness meters, file analysis and themes. These pages cover installing it and using it.

|---|---|
| [Install](install.md) | Docker, or PHP and Node directly; the first user; where the data is kept; updating |
| [First run](first-run.md) | Signing in, adding music, scanning and analysing |
| [The library](library.md) | The two panes, the keys, the command line, search, editing, folders |
| [Meters and posters](meters.md) | Choosing meters, full screen, what each meter shows |
| [File analysis](file-analysis.md) | What is measured, what each finding means, the Truth and Findings views |
| [Themes](themes.md) | Switching, editing, importing and exporting themes; the JSON format |
| [Sharing and playlists](sharing.md) | Accounts, sharing albums, tracks and playlists |
| [Clients](clients.md) | The Android app, the iOS app and the terminal client |
| [Configuration](configuration.md) | Settings, the tools Magnetite calls, storage in Ferrite |
| [Troubleshooting](troubleshooting.md) | Scans that do not start, no sound, uploads that fail |
